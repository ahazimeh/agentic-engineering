    -event triggering something you want, like when it always tries to forget using python instead of uv, you can add a hook to be triggered everytime you call a script to use uv instead of python

    -having a hook when claude finished doing its work
    3 things you can do
        -run a shell command
        -make a prompt to claude
        -agent you want claude to spawn a subagent

                        ]
                    }
                ]
            }
