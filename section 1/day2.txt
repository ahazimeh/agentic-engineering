Context Engineering
    Getting the right context (it was called prompt engineering but as the input became more complex this became Context Engineering)
        system prompt: overall framing (tone, overall situation, role this llm is playing)
        tools: description of capabilities
        memory: resource that persist across different conversations
        conversational history
            user message, llm reasoning, llm replies, code generated, tools called, results of code  and tools
        Agents.md (part of memory)
    context window (limit): poorer results when getting bigger context, and you will get an error when the context is over the limit (usually it does compacting when the context is close to getting filled (sometimes it misses stuff that is important))
